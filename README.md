# A Letter For You ♡

A little letter from the heart.

A Letter For You is a romantic, interactive website built using HTML, CSS, and JavaScript. With a vintage paper aesthetic, gentle animations, floating hearts, and a heartfelt question, it creates a simple yet memorable experience.

**Live Website:** [Visit Here ♡](https://officiallyhrithik.github.io/spices/)

## Features

- Elegant vintage letter design
- Floating hearts, leaves, and flowers
- Interactive Yes and No responses
- Smooth animations and transitions
- Personalized response messages
- Read Again option
- Responsive design for mobile and desktop
- Reduced-motion accessibility support

## Built With

- HTML5
- CSS3
- JavaScript

## Getting Started

### Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

### Deploy with GitHub Pages

1. Upload `index.html` and `README.md` to your GitHub repository.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Click **Save**.

Your website: [https://officiallyhrithik.github.io/spices/](https://officiallyhrithik.github.io/spices/)
